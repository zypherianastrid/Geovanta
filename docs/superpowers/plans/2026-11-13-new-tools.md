# 6 Tool Baru Geovanta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambahkan 6 tool baru (Curvature, Shape Builder, Blob Generator, Weave Generator, Line Segment, Arc) ke Geovanta sebagai tool toolbar dengan parameter di inspector kanan.

**Architecture:** Satu grup toolbar baru (`VE_DRAW_GROUP`) + cabang dispatch pointer per tool mengikuti pola Pen/Shape yang sudah ada; generator murni (Blob/Weave/Line/Arc) sebagai modul engine pure yang diuji unit (TDD), lalu wiring UI (drag, commit, inspector live-update) diuji probe Playwright; metadata generator menempel di objek (`gen`) dan ikut save/load via atribut `data-gen`.

**Tech Stack:** React 18 + CanvasKit (render), esbuild, `node --test` (unit), Playwright (probe), tanpa dependensi baru.

**Spec:** `docs/superpowers/specs/2026-11-12-new-tools-design.md` — rencana ini berargumen dari spec itu; executor membaca keduanya.
